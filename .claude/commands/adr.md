Konu: $ARGUMENTS

1. `docs/adr/README.md`'den sıradaki numarayı bul.
2. `docs/adr/0000-template.md`'yi kopyala → `docs/adr/NNNN-kisa-baslik.md`.
3. Bağlam, en az 2 seçenek (artı/eksi), önerilen karar, sonuçlar, doğrulama yaz. Dayanakları (kod, ölçüm, kaynak linki) ekle.
4. `Durum: Proposed`. README tablosuna ekle.
5. Ürün sahibine tek paragraf özet + önerini sun. Onay gelince `Accepted` ve tarih.

Mevcut bir ADR'yi değiştirmiyorsun; değişiklik gerekiyorsa yeni ADR "Supersedes ADR-XXXX" der.
